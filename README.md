## 예상 출제 포인트

1. **데이터베이스 보안**: 최근 OTT·플랫폼 DB 해킹 사례를 통해 접근 통제, 암호화, 침해 대응 절차가 시험 출제 대상이 될 가능성이 높음.  
2. **벡터·그래프 DB 및 온톨로지 연계**: 엔터프라이즈 AI 데이터 준비 단계에서 데이터 모델링·검색 성능 최적화 기술이 핵심 개념으로 출제될 수 있음.  
3. **AI 기반 CPS 보안**: AI 공격이 CPS에 미치는 영향과 공급망 보안 대책을 이해하는 것이 국가·산업 인프라 보호 영역에서 중요하게 다뤄질 전망.  
4. **개인정보보호 보험·재정 안전망**: 지방자치단체·공공기관의 사이버보험 적용 사례를 통해 법·규제·위험 관리 관점을 평가할 가능성 존재.
