## 예상 출제 포인트
1. **온톨로기 기반 보안 정보 통합**: 흩어진 사이버 위협 데이터를 개체-관계 모델로 표현하여 분석 효율성 향상
2. **그래프/벡터 기술의 보안 적용**: 보격 그래프(Graph)로 인과관계 분석 + 벡터(Vector)로 유사도 기반 위협 탐지
3. **AI와 온톨로지의 시너지**: 지식 구조화(AI) + 의미론적 연결(온톨로지)으로 사이버 공격 사전 경로 예측
