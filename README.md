## 예상 출제 포인트

1. **AI 보안 위협 (미토스 효과)**: AI 모델이 소프트웨어 취약점을 자율적으로 탐지하고 공격하는 기술의 등장으로 사이버 보안 패러다임 변화. 정보 비대칭성과 시간 비대칭성 심화로 전통적 방어 체계의 한계 드러남

2. **AI 생성 정보의 신뢰성**: AI가 생성한 허위 정보가 검색 엔진, 뉴스 피드, 학술 데이터베이스에 확산되면서 정보 품질 관리의 중요성 대두. 데이터 출처 검증 및 무결성 확보 방안 필요

3. **정보보안경영시스템 (ISMS)**: ISO 27001 인증의 요구사항과 심사 항목에 대한 이해. 정책, 물리적 보안, 접근 통제, 법적 준거성 등 종합적 보안 관리 체계
